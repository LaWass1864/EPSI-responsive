To-do : one page restaurant (v15)

On construit la page en blocs, du haut vers le bas. Chaque bloc est une Frame. Cochez au fur et à mesure. Le socle est à terminer avant 11h30 ; les bonus sont pour ceux qui avancent plus vite.

Règle : un élément rangé par un Stack est en Position Relative. En Absolute, il ne suit plus le Stack.

Les trois zones : Layers à gauche, le canevas au centre, Style à droite.

Socle : 0 / 0

Avant la séance

Étape 0 : créer son compte Framer

À faire avant mardi

Où : sur framer.com, « Sign up » en haut à droite. Choisissez « Continue with Google ».

Partie 1 : découverte de l'interface

Étape 1 : ouvrir un projet

5 min

Où : « New project » depuis l'accueil de Framer.

Étape 2 : la zone Layers (à gauche)

10 min

Où : l'onglet Layers. C'est la liste des éléments, rangés en hiérarchie. Cliquez sur un élément : il se sélectionne sur le canevas.

Étape 3 : la zone centrale (le canevas)

10 min

Où : la grande zone du milieu. Dans la barre du haut : le + (insérer), le carré en pointillés (Frame), le T (texte) et le triangle (forme). En haut à droite : Publish et le bouton ▷ (aperçu).

Étape 4 : la zone Style (à droite)

15 min

Où : à droite, quand un élément est sélectionné. Repérez :

Position : Type (Absolute, Relative, Fixed, Sticky) et les valeurs L, R, T, B.

Size : Width et Height, avec les menus Fixed, Relative, Fill.

Layout : Type (Stack ou Grid), puis Direction, Gap, Distribute, Align, Padding.

Étape 5 : un Stack avec deux Frames, et un visuel dedans

15 min

Où : insérez un Stack. Framer crée deux Frames vides dedans : gardez-les ou supprimez-en une (sélection dans Layers, puis Suppr). Ajoutez ensuite un visuel dans une Frame (par exemple un Wave Gradient). Sélectionnez-le, puis dans Style, Position : Type Relative. Dans Size, Width : Fill.

Partie 2 : la structure de la page

Étape 6 : le Stack vertical de la page

10 min

Où : la page est un Stack vertical (Layout : Type Stack, Direction ↕). Ses enfants, de haut en bas : Header, Photos, Menu, Réservation, Footer. Chaque bloc est une Frame, nommée dans Layers.

Partie 3 : le header

Étape 7 : le menu du haut (logo à gauche, menu à droite)

25 min

Où : dans le bloc Header, une Frame en Stack horizontal (Direction ↔, Distribute Space between, Align centre, Width Fill). Dans cette Frame : le logo (texte Le Jardin des Sources, bouton T), puis une Frame de menu en Stack horizontal, Gap 24, avec quatre textes : Offres, Carte, Contact, Réserver. Chaque lien est en Position Relative.

Étape 8 : le hero photo ou vidéo, dans le header

20 min

Où : sous la barre du menu, dans le Header, une Frame hero en Stack vertical, Width Fill, Height Fixed (par exemple 400). Dedans : une photo importée (bouton image) ou un visuel en Relative. Ajoutez un titre (T), par exemple Un café, des livres, un jardin, et un bouton Réserver.

Partie 4 : le reste de la page

Étape 9 : le bloc Photos du restaurant

20 min

Où : une Frame, Layout Grid, trois colonnes. Dedans, trois ou quatre photos importées, en Position Relative.

Étape 10 : le bloc Menu (la carte)

20 min

Où : une Frame, Layout Grid, trois colonnes, avec trois cartes de plats (Frame + textes). Textes : Croque du jardin 12 €, Salade de saison 11 €, Tarte aux fruits 6 €.

Étape 11 : le formulaire de réservation

25 min

Où : une Frame en Stack vertical, centrée, Width Fixed 600. Dedans : Nom, Email, Nombre de personnes, Date, puis un bouton Réserver.

Étape 12 : le footer

10 min

Où : une Frame en Stack horizontal, Distribute Space between. À gauche : © Le Jardin des Sources. À droite : Contact.

Étape 13 : vérifier dans Layers

5 min

Où : Layers. Stack (page) → Frame Header → (barre du menu, hero) → Frame Photos → Frame Menu → Frame Réservation → Frame Footer.

Pour la suite

B1 : effet au survol sur le menu

Où : sélectionnez un lien du menu, puis dans Style, la rubrique Hover (Survol) : changez la couleur.

B2 : le Wave Gradient en fond du hero

Où : mettez le Wave Gradient dans la Frame hero, en Position Relative et Width Fill, puis placez le titre par-dessus.

Rappel : si une étape bloque, dites-le à voix haute avant de passer à la suivante. Une étape bloquée à 11h20 doit être signalée tout de suite.
