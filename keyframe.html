Keyframes : avec ou sans 0 % et 100 % ?

Les deux boutons font exactement la même animation.

Avec 0 % et 100 %

@keyframes pulse-avec {
  0%, 100% { box-shadow: 0 0 10px #6c4cf1; }
  50%      { box-shadow: 0 0 30px #6c4cf1; }
}

Sans 0 % ni 100 %

@keyframes pulse-sans {
  50% { box-shadow: 0 0 30px #6c4cf1; }
}
