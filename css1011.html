En cas de blocage

Rien ne bouge : vérifie que le fichier est enregistré (Ctrl + S) et que Live Server est lancé.

Le menu ou les cartes ne s'alignent pas : vérifie que display: flex est sur le parent (header nav ou .cartes), pas sur les enfants.

Le badge ne se place pas bien : vérifie que la carte a bien position: relative.

Le menu ne reste pas en haut : vérifie top: 0.

L'animation ne se voit pas : ton ordinateur peut demander à réduire les animations. C'est un réglage à vérifier.

Une accolade manque : chaque { doit avoir son }.
